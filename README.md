# DeskFlow AI Assistant

Create a modern responsive web application called DeskFlow AI, an AI-powered workplace productivity assistant. Build the full prototype with a warm cream background, white cards, black typography, and a strong Substack-like orange accent. The design should feel minimal, premium, professional, and simple. Create a welcoming dashboard headed “Good morning 👋 What would you like to accomplish today?” with large clickable cards for Write an Email, Summarise Notes, and Plan My Tasks. Include productivity overview metrics: Tasks completed, Emails generated, Notes summarised. Add navigation (left sidebar on desktop, appropriate mobile navigation) with Dashboard, Email Generator, Meeting Summariser, Task Planner, History, Settings, Responsible AI. Implement functional polished screens/workflows: Email Generator form with recipient/audience, purpose, important details, tone options Formal/Friendly/Persuasive and generated professional email output; Meeting Notes Summariser textarea with output sections for concise summary, key discussion points, decisions made, action items, deadlines, responsible people; Task Planner supports multiple tasks with deadline and priority, organizes/prioritizes them and presents structured daily/weekly scheduling and time management suggestions. Use modern icons, rounded corners, subtle shadows, strong hierarchy, mobile responsiveness. Include the exact responsible-AI disclaimer visibly in relevant output areas: “AI-generated content may contain errors. Users should review and verify all important information before using or sharing it.” Make it feel like a real product, not a basic chatbot. Use credible example/demo data and interactions for a fully presentable prototype.
